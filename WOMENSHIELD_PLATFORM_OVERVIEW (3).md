# WomenShield Platform Overview
**Live at:** https://womenshield.com

## Mission
WomenShield provides critical, time-sensitive information to women facing domestic violence, healthcare access barriers, and economic challenges through a comprehensive, verified resource directory.

## Current Platform Capabilities

### Resource Directory (6,282+ Verified Resources)
- **Healthcare:** 373 clinics with geolocation and reproductive rights navigation
- **Emergency Shelters:** 585 shelters with real-time capacity tracking capability
- **Women-Owned Businesses:** 1,888 verified businesses across all sectors
- **Legal Resources:** State-by-state abortion and IVF law database
- **Coverage:** All 50 states + DC

### Technology Infrastructure
- **Geolocation:** OpenCage API integration for proximity-based search
- **Partner Portal:** Real-time updates from shelters, businesses, government agencies
- **Authentication:** Secure Replit Auth + Google OAuth
- **Database:** PostgreSQL with 15+ tables, UUID architecture
- **Frontend:** React + TypeScript with responsive design
- **Backend:** Express.js with RESTful API

### Recently Implemented (December 2024)
✅ Geocoding for all healthcare/shelter resources
✅ Partner portal with three-tier access system
✅ Real-time shelter capacity update capability
✅ Reproductive rights law navigator (12 states with bans tracked)
